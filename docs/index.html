Features

Everything your team needs

From raw transcript to structured insights in seconds. No cloud, no SaaS — just your terminal.

🎯

Decisions extracted

Automatically identifies and tags every decision made during the meeting with owner and confidence score.

✅

Task detection

Finds action items, assigns owners from context, and flags missing deadlines before they become blockers.

⚠️

Risk identification

Surfaces blockers and risks mentioned in conversation — even when they're not explicitly labeled as such.

📈

Drift tracking

Compares meeting-to-meeting to detect topic drift, unresolved decisions, and recurring blockers.

👁

--watch mode

Monitor a folder for new transcripts and get instant analysis as meetings finish — zero manual steps.

📦

Batch processing

Run analysis across dozens of files at once with --since, --filter, and --title flags.

AI Providers

Your model, your choice

TeamPulse supports multiple AI providers out of the box. Switch with a single flag — no code changes needed.

✨ Google Gemini Default

Best speed-to-quality ratio for meeting analysis. Gemini 2.0 Flash handles long transcripts with ease.

gemini-2.0-flash gemini-1.5-pro gemini-1.5-flash
🤖 Anthropic Claude

Superior reasoning for complex multi-speaker transcripts. Claude 3 excels at nuanced context understanding.

claude-3-5-sonnet claude-3-haiku claude-3-opus
⚡ OpenAI GPT-4

Industry-standard reliability. GPT-4o delivers consistent structured output for all transcript formats.

gpt-4o gpt-4o-mini gpt-4-turbo

CLI Reference

Powerful flags, simple syntax

Every command designed for real workflows — pipe, script, automate.

teampulse analyze Single file
Analyze a single transcript file and print structured results.
❯ teampulse analyze meeting.txt
--provider AI model
Switch AI provider without changing config.
❯ teampulse analyze m.txt --provider claude
--watch Live monitoring
Watch a folder and auto-analyze new transcripts as they appear.
❯ teampulse analyze --watch ./meetings/
batch + --since Date filter
Process all transcripts since a date. ISO format or relative.
❯ teampulse batch ./ --since 2026-05-01
--filter Type filter
Filter output to a specific insight type: risk, task, decision.
❯ teampulse batch ./ --filter risk
--title Label output
Tag your analysis with a custom title for reports and logs.
❯ teampulse analyze m.txt --title "Sprint 12"

Installation

Up and running in 2 minutes

TeamPulse runs on Node.js 18+. Pick your platform and follow the steps below.

🍎 macOS & Linux
1
Verify Node.js 18+
Make sure you have Node.js 18 or higher installed.
node --version
2
Clone & install dependencies
Clone the repo and install all npm packages.
git clone https://github.com/mcontrerasmalpar-pixel/teampulse.git
cd teampulse && npm install
3
Configure your API key
Copy the example env file and add your Gemini API key.
cp .env.example .env
Open .env and set GEMINI_API_KEY, ANTHROPIC_API_KEY, or OPENAI_API_KEY — whichever provider you want to use.
4
Link globally
Make the teampulse command available system-wide.
npm link
5
Run your first analysis
Drop a transcript in the data folder and analyze it.
teampulse analyze data/sample.txt
🪟 Windows (PowerShell)
1
Verify Node.js 18+
Open PowerShell and check your Node version.
node --version
2
Clone & install dependencies
Clone the repo and install all npm packages.
git clone https://github.com/mcontrerasmalpar-pixel/teampulse.git
cd teampulse; npm install
3
Configure your API key
Copy the example env file and add your API key.
Copy-Item .env.example .env
Open .env and set GEMINI_API_KEY, ANTHROPIC_API_KEY, or OPENAI_API_KEY — whichever provider you want to use.
4
Link globally
Make the teampulse command available system-wide.
npm link
5
Run your first analysis
Drop a transcript in the data folder and analyze it.
teampulse analyze data/sample.txt
★
Optional: publish to npm
Share your fork on the npm registry.
npm login
npm publish --access public
