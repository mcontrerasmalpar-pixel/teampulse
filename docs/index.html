Features

Everything your team needs

From raw transcript to structured insights in seconds. No cloud, no SaaS — just your terminal.

🎯

Decisions extracted

Automatically identifies and tags every decision with owner and confidence score.

✅

Task detection

Finds action items, assigns owners from context, and flags missing deadlines.

⚠️

Risk identification

Surfaces blockers and risks — even when they're not explicitly labeled as such.

📈

Drift tracking

Compares meeting-to-meeting to detect topic drift and recurring blockers.

🏠

Fully local mode

Run analysis 100% offline with Ollama. No API keys, no data leaving your machine.

📦

Batch processing

Run analysis across dozens of files with --since, --filter, and --title.

AI Providers

Your model, your choice

Switch providers with a single flag — cloud or fully local. No code changes, no config rewrite.

🏠
New in v0.2.0 — Local providers
Run TeamPulse completely offline with --provider ollama or --provider mistral. No API key required for Ollama — just ollama pull mistral and you're set.

Run any supported model on your own hardware. Zero data leaves your machine — ideal for sensitive meeting content.

CLI Reference

Powerful flags, simple syntax

Every command designed for real workflows — pipe, script, automate.

teampulse analyzesingle file
Analyze a single transcript and print structured results.
❯ teampulse analyze meeting.txt
--providerAI model
Switch AI provider without changing config. Supports gemini · claude · openai · mistral · ollama.
❯ teampulse analyze m.txt --provider mistral
--provider ollamaoffline
Run fully locally via Ollama. No API key needed. Use --model to pick the model.
❯ teampulse analyze m.txt --provider ollama --model llama3
--watchlive mode
Watch a folder and auto-analyze new transcripts.
❯ teampulse analyze --watch ./meetings/
batch + --sincedate filter
Process all transcripts since a date.
❯ teampulse batch ./ --since 2026-05-01
--filtertype filter
Show only a specific insight type: risk · task · decision.
❯ teampulse batch ./ --filter risk

Installation

Up and running in 2 minutes

TeamPulse runs on Node.js 18+. Pick your platform and follow the steps.

🍎macOS & Linux
1
Verify Node.js 18+
Make sure you have Node.js 18 or higher.
node --version
2
Clone & install
Clone the repo and install dependencies.
git clone https://github.com/mcontrerasmalpar-pixel/teampulse.git
cd teampulse && npm install
3
Configure API keys
Copy the env file and add your key. Skip this step if using Ollama locally.
cp .env.example .env
Set GEMINI_API_KEY, ANTHROPIC_API_KEY, OPENAI_API_KEY, or MISTRAL_API_KEY in .env
4
Optional: install Ollama
For fully offline analysis — no API key needed.
brew install ollama
ollama pull mistral
Offline mode: once pulled, works without internet
5
Link globally & analyze
Make teampulse available system-wide, then run your first analysis.
npm link
teampulse analyze data/sample.txt --provider ollama
🪟Windows (PowerShell)
1
Verify Node.js 18+
Open PowerShell and check your Node version.
node --version
2
Clone & install
Clone the repo and install dependencies.
git clone https://github.com/mcontrerasmalpar-pixel/teampulse.git
cd teampulse; npm install
3
Configure API keys
Copy the env file and add your key. Skip if using Ollama.
Copy-Item .env.example .env
Set GEMINI_API_KEY, ANTHROPIC_API_KEY, OPENAI_API_KEY, or MISTRAL_API_KEY in .env
4
Optional: install Ollama
Download from ollama.com and pull a model.
ollama pull mistral
Offline mode: works without internet once pulled
5
Link globally & analyze
Make teampulse available system-wide, then analyze.
npm link
teampulse analyze data/sample.txt --provider ollama
