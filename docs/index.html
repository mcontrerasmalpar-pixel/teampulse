Features

Built for teams that ship.

No dashboards. No browser tab. No SaaS subscription. Just your terminal and your meeting transcripts.

Structured extraction

Decisions with owners, tasks with priorities, risks with mitigations, open questions — all parsed from plain text using Gemini 2.0 Flash.

Decision drift detection

Compare any two meetings and see a scored diff of every decision and task. Know exactly what regressed, what's recurring, and who didn't follow through.

Watchdog monitor

Scan your entire meeting history for risks with no owners, tasks that keep recurring without resolution, and overloaded team members.

Conversational REPL

Chat with your meeting history using natural language. Ask about owners, blockers, or patterns — Gemini maintains full context across every analyzed meeting.

Role-based analysis

Analyze the same transcript through four lenses: Product Manager, Developer, Founder, or Marketing. Each surfaces what matters most to that role.

Markdown & JSON export

Output rich Markdown with YAML frontmatter, GitHub-style checkboxes, priority grouping, and unassigned-task warnings. Ready for Notion, GitHub, or Obsidian.

Commands

Six commands. One workflow.

Composable, scriptable, and exit-code safe — fits any CI or automation pipeline.

teampulse analyze <file>

Analyze a transcript

Read any .txt file and extract structured intelligence. Supports --skill, --format json|markdown, and --output.

teampulse drift [idA] [idB]

Detect decision drift

Compare two meetings side-by-side with a drift score per item. Use --last 2 to auto-select the two most recent.

teampulse watchdog

Scan for recurring risks

Full history scan for unresolved risks, ownerless tasks, and overloaded participants. Filter by team with --team.

teampulse chat

Interactive REPL

Conversational interface over your full meeting history. Slash-command support: /meetings, /use <id>, /clear.

teampulse history

Browse past meetings

Table view of all stored meetings with decision, task, and risk counts. Unassigned tasks highlighted.

teampulse init

Setup wizard

Guided interactive setup — API key, default skill, team name. Writes your .env automatically.

Get started

Up and running in 3 steps

Requires Node.js 18+ and a free Gemini API key from Google AI Studio.

1

Clone the repository

Pull the source directly from GitHub.

git clone https://github.com/mcontrerasmalpar-pixel/teampulse.git && cd teampulse
2

Install & configure

Install dependencies, then run the setup wizard to add your Gemini API key.

npm install && node src/index.js init

Get a free key at aistudio.google.com/app/apikey

3

Analyze your first meeting

Point TeamPulse at any .txt transcript — Google Meet, Otter, or Fireflies all work.

node src/index.js analyze data/sample-meeting.txt --skill product-manager

Optional: install globally to use teampulse from any directory

npm install -g . && teampulse --help
